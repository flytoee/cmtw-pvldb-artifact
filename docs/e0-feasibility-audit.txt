Scope
-----
This audit precedes every v4 code or experiment. It verifies that the proposed
experiments use synthetic data, entirely local inference, automatic evaluation,
and no restricted public characters.

Gate 1 — data
---------------

The existing v3 generator already records synthetic_only, no_human_subjects,
no_training, no_public_character_lore, and restricted_characters_absent.
V4 will preserve these fields and add explicit seeds, true derivation graphs,
and automatic oracle predicates.

Gate 3 — fully automatic evaluation
------------------------------------
PASS. V4 will use a generator-side exact oracle for state, admission,
true-derivation coverage, closure, and canary leakage. A local LLM judge may
be added only as a separately reported semantic-paraphrase leakage check; it
will never define contract correctness. No human participant or human rating is
part of the protocol.

IP audit
--------
PASS. Exact-name scans of data/, scripts/, and results/ found zero occurrences
of: 散兵, 杜林, 基尼奇, 洛恩, Scaramouche, Wanderer, Durin, Kinich, or Lohn.
An initial substring scan falsely matched the ordinary word "during" against
"Durin"; this was corrected with whole-word matching and is retained as an
audit note. V4 generation and results directories must be scanned before every
snapshot is accepted.

Frozen v3 baseline
------------------
The pre-v4 manuscript source, PDF, Chinese reading draft, and bibliography are
preserved in docs/paper/frozen/cmtw_v3_pre_v4_20260726/. Their hashes appear in
that directory's freeze-manifest.txt. V4 uses new filenames and must not edit
the frozen snapshot.
